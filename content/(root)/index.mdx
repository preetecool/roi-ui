## About

Roi UI is an open source library of React components and blocks. The components are accessible, styled, and ready to use.

You copy each component into your project, so you own the source code and can change any part of it. This approach comes from [shadcn/ui](https://ui.shadcn.com/).

The name Roi comes from the Greek word ροή (said *roí*), which means "flow". We want building and using an interface to feel easy and natural, like water moving through a well-made system.

## Base UI

Most Roi UI components use [Base UI](https://base-ui.com/) primitives. Base UI handles behavior and accessibility, such as focus, keyboard use, and screen reader support. Roi UI adds the styles.

Base UI was made by people from the Radix UI team. It is part of the MUI family of projects and is built for long-term support.

## Motion

Some components use animation, built with [Motion](https://motion.dev/) (formerly Framer Motion) or CSS.

Every animation in Roi UI has a job. It shows what changed, points to where to look, or confirms an action. We keep animations small, so they help without distracting.

## Styling

You can style components with CSS Modules or Tailwind. Both versions look and work the same, so pick the one that fits your project.
