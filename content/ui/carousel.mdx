## Anatomy

<CodeBlock
filename="anatomy"
  language="tsx"
  code={`import { Carousel } from "@/components/ui/carousel";

<Carousel.Bleed>
  <Carousel.Root variant="inset">
    <Carousel.Viewport>
      <Carousel.Item>Item 1</Carousel.Item>
      <Carousel.Item>Item 2</Carousel.Item>
      <Carousel.Item>Item 3</Carousel.Item>
    </Carousel.Viewport>
    <Carousel.Navigation>
      <Carousel.Previous />
      <Carousel.Next />
    </Carousel.Navigation>
    <Carousel.Indicators />
  </Carousel.Root>
</Carousel.Bleed>
`} />

## Props

### Root

Manages the index and provides context. It counts the slides itself: each direct child of the viewport is one slide.

<PropTable
    data={[
        {
            prop: "variant",
            type: '"default" | "inset"',
            default: '"default"',
            description: "Use 'inset' inside Carousel.Bleed to align the first and last slide with the parent of the bleed",
        },
        {
            prop: "index",
            type: "number",
            description: "Controlled index value",
        },
        {
            prop: "defaultIndex",
            type: "number",
            default: "0",
            description: "Default index for uncontrolled mode",
        },
        {
            prop: "onIndexChange",
            type: "function",
            description: "Callback when index changes",
        },
        {
            prop: "className",
            type: "string",
            description: "Additional CSS classes to apply to the carousel container",
        },
    ]}
/>

### Bleed

Optional wrapper that makes the carousel as wide as the window. Put it around `Carousel.Root`.

<PropTable
    data={[
        {
            prop: "className",
            type: "string",
            description: "Additional CSS classes to apply to the bleed container",
        },
    ]}
/>

### Viewport

The scroll container and the slide track. Set the space between slides with the `--carousel-gap` CSS variable (default `1rem`).

<PropTable
    data={[
        {
            prop: "className",
            type: "string",
            description: "Additional CSS classes to apply to the viewport",
        },
    ]}
/>

### Item

One slide. The arrow keys, Home, and End move the carousel when the slide has focus.

<PropTable
    data={[
        {
            prop: "className",
            type: "string",
            description: "Additional CSS classes to apply to the item",
        },
    ]}
/>

### Navigation

Container for navigation buttons with default Previous/Next rendering.

<PropTable
    data={[
        {
            prop: "className",
            type: "string",
            description: "Additional CSS classes to apply to the navigation container",
        },
        {
            prop: "children",
            type: "ReactNode",
            description: "Custom navigation buttons (defaults to Previous and Next)",
        },
    ]}
/>

### Previous

Previous button that auto-disables at start.

<PropTable
    data={[
        {
            prop: "className",
            type: "string",
            description: "Additional CSS classes to apply to the previous button",
        },
        {
            prop: "children",
            type: "ReactNode",
            description: "Custom content for the previous button (defaults to left arrow icon)",
        },
    ]}
/>

### Next

Next button that auto-disables at end.

<PropTable
    data={[
        {
            prop: "className",
            type: "string",
            description: "Additional CSS classes to apply to the next button",
        },
        {
            prop: "children",
            type: "ReactNode",
            description: "Custom content for the next button (defaults to right arrow icon)",
        },
    ]}
/>

### Indicators

One button for each slide (hidden when there is only one slide). The active button has `data-active` and `aria-current`.

    data={[
        {

        },
    ]}
/>
